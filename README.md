# NutriDex
NutriDex（ニュートリデックス）かんたん操作ガイド
NutriDexは、文部科学省の公的データに基づき、あらゆる食品のカロリーや詳細栄養素（ビタミン・ミネラル・アミノ酸・PFC比率）を「生活実感のある単位」ですぐに調べられる栄養辞書・計算ツールです。登録不要で、開いてすぐに使えます。
🚀 基本の使い方（5つのメイン機能）
1. 食材をさがす（検索）
￼ 文字入力検索: 検索窓に「もやし」「豚バラ」「白米」など、ひらがな・漢字で入力するだけで候補が絞り込まれます。
￼ クイックフィルター: 「高タンパク」「低糖質」「食物繊維」「50kcal以下」などをワンタップで絞り込み可能です。
￼ AI推定照会: 一覧にない食品名を入力した場合、「AI推定照会」ボタンを押すと文科省基準に基づいた推計データを自動取得します。
2. 分量を合わせる（生活単位＆スライダー）
￼ 生活単位チップ: 「市販1袋（200g）」「茶碗普通盛（150g）」「一口大（30g）」などの日常単位をタップするだけで、その分量に切り替わります。
￼ 無段階スライダー: 「-10g」「+10g」ボタンやスライダーバーで、5g〜500gまで細かく分量を微調整できます。
￼ 廃棄率の自動計算: キャベツ1/4玉など「芯や皮付きの購入時重量」を選んだ場合、廃棄率を自動で引いた純粋な可食部ベースで計算されます。
3. 栄養素をチェックする（詳細ダッシュボード）
￼ PFC比率帯グラフ: タンパク質（赤）、脂質（黄）、炭水化物（青）のエネルギーバランスが一目で分かります。
￼ カテゴリ切り替えタブ: 「すべて」「基本・熱量」「糖質・食物繊維」「ミネラル」「ビタミン」「脂質・脂肪酸」「アミノ酸」をワンタップで切り替え可能です。
￼ 1食分の充足率メーター: 厚生労働省「日本人の食事摂取基準」に基づき、1食分目安に対する充足率（%）がバーで表示されます（食塩相当量などは上限超過アラート表示）。
4. 2つの食材を比べる（くらべる / VS機能）
￼ 「緑豆もやし」vs「大豆もやし」のように、2つの食材を左右に並べて比較できます。
￼ 低カロリー、高タンパク、高食物繊維など、健康面で優れた項目には自動で「★バッジ」が付きます。
￼ 「左右スワップ」ボタンで配置をワンタップで入れ替え可能です。
5. 料理の栄養を合算・按分する（けいさん / レシピ）
￼ カートのように食材を複数追加し、料理全体の総カロリーやPFCを合算できます。
￼ 「1〜6人前」の人数セレクターを選ぶと、1人前あたりの栄養価が自動で按分計算されます。
￼ 「コピー」ボタンを押すと、栄養サマリーをクリップボードに整形テキストとしてコピーでき、SNSやメモ帳にそのまま貼り付けられます。
💡 便利な機能・ワンポイント
機能
使い方
パーソナライズ設定
右上の人型/設定アイコンから「性別」と「年代（20代以下 / 30〜40代 / 50〜64歳）」を変更すると、食事摂取基準のゲージが自動であなた向けに最適化されます。
お気に入り＆履歴
食材詳細の「しおり（ブックマーク）」アイコンをタップすると保存タブへストックされ、いつでも素早く呼び出せます。
サマリーテキストコピー
詳細画面やレシピ画面の「コピー」ボタンで、PFCや主要ミネラル・ビタミンを含む集計メモを即座に共有できます。
